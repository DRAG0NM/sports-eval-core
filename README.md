# Sports Eval Core · Obsidian 运动评估模板

一个本地优先、可审计、面向 Obsidian 的个人运动与恢复趋势分析框架。

它把结构化运动/睡眠输入转换为：

- 可在 Obsidian 阅读和维护的训练日志、周报告与复盘页面；
- 供程序或 AI 使用的确定性指标；
- 带 `as_of`、部分周、数据缺失与实验性标记的可追溯输出。

## 项目边界

本公开版本：

- 不包含任何厂商账号、网页抓取器或私有接口；
- 不包含真实个人健康、睡眠、位置或训练记录；
- 示例数据全部为合成数据；
- 只用于个人健康管理、教育和研究，不用于疾病诊断、治疗或紧急决策。

完整边界见 [[PRIVACY]] 与 [[DISCLAIMER]]。

## 快速开始

要求 Python 3.9+，核心运行时没有第三方依赖。

```powershell
python scripts/build_report.py examples/synthetic_week.json
python -m unittest discover -s tests -p "test_*.py"
python scripts/release_audit.py
```

生成的周报告会写入 `06_周报告/`。随后在 Obsidian 中选择“打开本地仓库”，打开本目录即可。

入口页面：[[00_首页]]。

## 设计原则

1. 原始数据与公开代码分离。
2. 设备字段先归一，再计算指标。
3. 缺失数据显式降级，不填造数值。
4. 描述性指标不冒充因果模型或医疗判断。
5. 自动生成区与用户笔记区分离。
6. 相同输入产生相同输出。
