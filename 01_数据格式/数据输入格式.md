# 数据输入格式

输入格式由 `schema_version` 管理，当前版本为 1。完整 JSON Schema：`schemas/weekly_input.schema.json`。

## 时间语义

- `week.mon` / `week.sun`：报告所属自然周。
- `week.as_of`：本次报告实际拥有数据的截止日。
- `week.partial`：当前周尚未结束时为 `true`。
- 日期使用 `YYYYMMDD`。
- 睡眠区间使用带时区的 ISO 8601 时间，例如 `2026-08-10T23:30:00+08:00`。

## 负荷语义

- `hr_zone_minutes` 必须是五个心率区间的分钟数。
- `load_history` 是“日期 → 同一口径负荷”的映射；没有活动的日期按休息日 0 处理。
- 不要把设备每日状态、恢复建议或训练指数跨日求和后当成训练负荷。
- ACWR/EWMA 只在至少具有约 21 天历史跨度时输出，并始终标记为实验性。

## 隐私

公开示例只能使用合成数据。真实数据应放在 `.gitignore` 已排除的 `private/` 或外部目录中。
