# AI 教练运行层

公开版提供模型中立的最小实现 `scripts/coach_core.py`。它不调用任何云模型，也不上传输入。

## 工作流

1. `context` 从厂商无关 weekly input 构造 Context v2。
2. 运行层先处理主观事件并计算绿/黄/红安全门。
3. AI 只读取 Context v2，输出符合 `schemas/coach_response.schema.json` 的 Response v2。
4. `validate` 检查任务/日期、动作权限、计划确认、JSON Pointer、观测值和证据层。
5. 验证通过只代表契约与边界通过；科学质量仍需真实影子运行和行为评测。

## 安全门

- 红灯：胸痛、晕厥、无法承重、关节畸形等；训练动作全部挂起，必须紧急求助。
- 黄灯：疼痛、疾病、功能受限或恶化；阻止正常加量与课表推进。
- 绿灯：未记录上述信号；不代表绝对安全，只表示输入中没有确定性红黄灯。

模型不能把安全级别向下改写。安全门不是诊断器，也不替代专业人员。

## 证据层

| 层 | 含义 |
|---|---|
| `raw_signal` | 原始/标准化单指标 |
| `deterministic_metric` | 透明确定性计算或安全门 |
| `experimental_model` | 个人基线、多维状态、变化候选 |
| `user_event` | 主观恢复、RPE、疼痛等本人输入 |
| `plan` | 当前训练计划 |

实验层不能标高置信度，也不能单独触发增减量、停训或就医建议。

## Token 预算

默认预算：日常 3500、运动后 3500、周复盘 5000、疼痛随访 3000 个粗估 Token。估算只用于工程回归，不代表模型计费。

## 隐私

公开仓库只提供合成事件和合成响应。真实 Context、Response、主观事件和模型遥测应留在使用者本机，并由 `.gitignore` 排除。
